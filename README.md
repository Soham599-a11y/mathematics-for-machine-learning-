# Mathematics for Machine Learning

An independent learning portfolio documenting my study of the mathematical and computational foundations of Machine Learning and Artificial Intelligence.

## Areas of Study

### 1. Linear Algebra
- Vectors and vector spaces
- Matrices and linear transformations
- Systems of linear equations
- Linear independence and basis
- Orthogonality and Gram-Schmidt
- Eigenvalues and eigenvectors
- Matrix factorisation

### 2. Multivariable Calculus
- Functions of several variables
- Partial derivatives
- Gradients and directional derivatives
- Multivariable chain rule
- Jacobians and Hessians
- Taylor approximations
- Optimisation

### 3. Numerical Methods
- Gaussian elimination
- Matrix decompositions
- Numerical stability
- Computational linear algebra

### 4. Scientific Computing
- Python
- NumPy
- Matplotlib
- Numerical implementations

### 5. Machine Learning
- Linear and logistic regression
- Gradient descent
- Neural networks
- Backpropagation
- Deep learning fundamentals

## Purpose

The objective of this repository is to develop a rigorous understanding of the mathematics underlying modern machine learning systems through theoretical study, problem-solving and computational experimentation.

## Repository Structure

This repository will gradually contain mathematical notes, worked exercises, Python implementations and independent experiments.
